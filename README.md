# 3D 台球瞄准练习

Vite + Three.js 的中文单页练习工具：随机生成“母球能把目标球打进至少一个袋口”的局面，自动选中切角最小的袋口，并在 3D 球桌上画出进球线、ghost 球、瞄准线、瞄准点和接触点。所有贴图程序化生成，无外部图片。

## 开始

```bash
pnpm install
pnpm dev
```

`pnpm dev` 启动 Vite 开发服务器，浏览器打开终端提示的地址即可。

```bash
pnpm build    # 生成可部署的 dist/ 静态产物
pnpm test     # node:test 运行纯几何模块测试
```

## 操作说明

- **随机摆球**：重新生成一对母球/目标球，同时刷新袋口高亮、进球线、ghost 球、瞄准线、瞄准点与接触点。
- **视角**：拖拽旋转，滚轮缩放；平移已禁用，相机被限制在不会穿地或丢失球桌的范围内。
- **隐藏/显示进球线和瞄准线**：按钮只在“隐藏”和“显示”之间切换两条辅助线，默认显示。ghost 球、瞄准点、接触点与袋口高亮始终可见；重新摆球后保持当前显隐状态。

## 几何说明

- 单位：米。有效台面 2.54 × 1.27，球半径 0.028575，台面 y = 0，球心高度 y = R；x 为长轴，z 为短轴。
- 六个袋口：四个角袋在 `(±1.27, ±0.635)`，两个中袋在 `(0, ±0.635)`；袋口顺序固定，也是切角平局时的裁决顺序。
- 设目标球心 T、袋口 P、ghost 球心 G、接触点 K，`u = unit(T − P)`，则 `G = T + 2R·u`、`K = T + R·u`。进球线为 T→P，瞄准线为母球心 C→G。
- 切角是 C→G 与 T→P 的夹角，直球为 0°，可行范围 `[0°, 80°)`。
- 一个袋口可行需同时满足：母球、目标球、ghost 球心都在台内；两球不重叠且母球距 ghost 至少 0.15 m；母球不挡 T→P；目标球不挡 C→G；目标球进袋路径不先撞库；切角小于 80°。
- 选袋时枚举六个袋口，取可行且切角最小者；切角差在 1e-9 内按袋口顺序取先者。
- 随机摆球在台内缩进 0.035 m 的区域内采样，要求两球中心距至少 0.22 m，并用 `createShot` 校验；最多重采样 500 次，失败显式抛错。

几何逻辑集中在 `src/geometry.js`，不依赖 three，可直接用 `node:test` 验证；渲染层只消费它的结果。
