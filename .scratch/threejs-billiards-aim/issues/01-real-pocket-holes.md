# 01: 真实袋洞——深色袋桶与围板净空

**What to build:** 把 6 个袋口从“框顶亮金色圆环 + 扁平圆片”改成真实袋洞：布面圆孔与木框/库边缺口共同构成开口，框孔内壁在框/库边一侧由深色内衬遮挡，袋桶向下延伸出有纵深的袋壁与袋底；围板在袋口处开净空，袋腔全程不被木板挡住、近景不露木板。注意内衬上沿不能整圈抬到框顶：台面朝向的开口侧必须贴齐布面，否则约 4 cm 的筒壁会遮住布面开口。袋口半径与坐标继续取 `POCKETS[].mouthRadius`，瞄准/选袋/碰撞几何与 `node:test` 不变。

**Blocked by:** None (can start immediately)

**Status:** done

## Acceptance criteria

- [ ] 布面开孔半径仍等于 `mouthRadius`；木框缺口仍按 `mouthRadius + FRAME_CUT_MARGIN` 与同一组 `POCKETS` 坐标；未改几何模块、测试断言或任何袋口数值。
- [ ] 静态金色 Torus 与框顶扁平 collar/Ring 已移除；袋口不再由亮金色环或桌面上独立的一圈来表现。
- [ ] 每个袋口有深色哑光内衬袋桶：布面处口径 = `mouthRadius` 且与布面孔对齐，袋底约 y=-0.12（布面以下深度 ≥ 0.10 m），壁与底在近景可见，底部封闭、无透光缝，无自发光。
- [ ] 内衬上沿不得整圈抬高：台面朝向侧贴齐 y=0；抬高/外扩只出现在木框/库边朝向弧段（用于遮框孔内壁）；从台面中心一侧近看，布面开口不被筒壁遮挡。
- [ ] 围板在 6 个袋口处开净空（半径 ≥ `mouthRadius + 0.009`），顶面 y=-0.020、底面 y=-0.14 不变，其余部分连续；袋桶与围板不穿插。
- [ ] 默认视角、角袋近景、中袋近景截图中：6 个袋口都读成有纵深的暗洞；从任何近景角度看向袋腔都只见深色内衬，不露木板/围板。
- [ ] 当前选中袋口的青色高亮环、瞄准线/ghost/瞄准点/接触点行为不变；随机摆球、显隐按钮、拖拽/缩放不回归。
- [ ] `pnpm test`、`pnpm build` 通过；浏览器 console/page error 为 0；无新增依赖、无外部图片。
- [ ] 无 TODO、无临时调试代码或调试入口。
