# 03: 随机局面与瞄准可视化交互

**What to build:** 把几何核心接入已渲染的球桌：页面加载及点击“随机摆球”时生成合法局面；按最小切角自动选袋并在场景中高亮；显示目标球→袋口的进球线、目标球后方的半透明 ghost 球、母球→ghost 球心的瞄准线、瞄准点与目标球表面接触点；“隐藏/显示进球线和瞄准线”按钮只切换两条线且默认显示，ghost 球、瞄准点、接触点与袋口高亮不受影响，显隐状态跨局面保持；最后补齐 README。

**Blocked by:** 02

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 页面加载及每次点击“随机摆球”，两球位置、袋口高亮、进球线、ghost 球、瞄准线、瞄准点、接触点同步更新；局面通过纯几何模块校验。
- [ ] 选中袋口为切角最小的可行袋，并在场景中有醒目的发光/高亮效果。
- [ ] 进球线连接目标球心与袋口；ghost 球心在目标球心背离袋口 2R 处；瞄准线连接母球心与 ghost 球心；接触点在目标球表面朝向母球一侧；线抬离布面不闪烁。
- [ ] “隐藏进球线和瞄准线”按钮只控制两条线，默认显示；ghost 球、瞄准点、接触点、袋口高亮始终可见；再次点击恢复；重新摆球后保持当前显隐状态。
- [ ] README 写明 `pnpm install` / `pnpm dev` / `pnpm build`、操作说明（随机摆球、视角操作、显隐按钮）与几何说明。
- [ ] 视觉维持票 02 标准；无 TODO。
- [ ] `pnpm test`、`pnpm build` 通过。

## Verification

- 执行 `pnpm test`、`pnpm build`。
- 本地启动 Vite，在浏览器中：连续点击随机摆球至少 5 次，确认标记同步且选中袋口高亮；切换显隐按钮两次，确认只有两条线变化；拖拽与滚轮确认视角可用；截图留证。结束后停掉服务并清理临时产物。
