# 02: 逼真 3D 球桌与球体场景

**What to build:** 在页面中渲染完整 3D 球桌与两颗球：木框、绿呢、立体库边、六个带金属圈的深色袋口，标准尺寸摆放的母球与目标球；程序化 canvas 布纹/木纹/球面贴图（目标球带号码或条纹）、PBR 材质与环境反射、方向光阴影、ACES 色调映射；固定最佳初始视角，OrbitControls 支持拖拽旋转和滚轮缩放（禁用平移）；窗口尺寸自适应。本票用固定合法位置展示场景，暂不接随机按钮与瞄准标记。

**Blocked by:** 01

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 浏览器打开可见完整球桌：木框、绿呢、6 个袋口（深色袋洞 + 金属圈）、有立体库边细节；无占位方块、纯色平面或外部图片。
- [ ] 母球与目标球为标准半径，球面使用程序化贴图（可见号码或条纹）、高光/环境反射，能向台面及其他物体投影。
- [ ] 初始相机固定为同时看清全桌与两球的角度；OrbitControls 旋转/缩放可用，平移禁用，有距离与极角限制。
- [ ] 阴影、色调映射、窗口缩放与动画循环正常。
- [ ] `pnpm test`、`pnpm build` 通过；无 TODO。

## Verification

- 执行 `pnpm test`、`pnpm build`。
- 本地启动 Vite，用浏览器（或 headless Chrome 截图）确认球桌、袋口、球体与光影；结束后停掉服务并清理临时产物。

## Skills

- None（three.js 常规用法；尺寸、坐标与材质要求遵循 spec Decisions）。

## Out of scope

- 随机摆球、自动选袋、进球线/瞄准线/ghost 球/标记、显隐按钮。
- 最终 README 操作说明。
